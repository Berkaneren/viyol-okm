# Viyol OKM

Keskinoğlu Viyol fabrikası Operasyon Komuta Merkezi: üretim, duruş, fire, hammadde, sevkiyat, maliyet ve işçilik göstergeleri.

Telefona kurulabilen web uygulamasıdır (PWA). Veriler sayfada **şifreli** durur; görüntülemek için ekip şifresi gerekir.

**Kurulum:** iPhone'da Safari → Paylaş → Ana Ekrana Ekle · Android'de Chrome → Uygulamayı yükle.

Güncelleme: yalnızca `index.html` ve `sw.js` değişir.
